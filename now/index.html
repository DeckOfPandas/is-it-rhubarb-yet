--- title: This week description: What is in season in the UK right now. permalink: /now/ --- {%- comment -%} All 52 weekly lists are rendered at build time. JavaScript reveals the one for today (or ?week=N) and wires the previous/next buttons. Without JavaScript every week shows, in order. For each food and week: "in" if any variety is fully in season; otherwise "out" (going out) if a variety's just-about range follows its in-season range, or "coming" if it precedes one. Year ends count as adjacent. The in-season list is written once per week, A to Z, and each item carries its rank under the three orders as --os (newest first: fewest weeks since the season began), --oa (A to Z) and --og (by culinary group, A to Z within it). The order switch picks which rank the grid lays out by, so the list is not repeated. Group headings are items that only show in group order. Entries are "key|group|slug|shown name|colour|weeks since start" strings sorted as text, so numbers in keys are padded by adding 100. {%- endcomment -%}
