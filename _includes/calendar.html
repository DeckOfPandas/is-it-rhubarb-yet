{% comment %} The whole-year chart as one inline SVG. Expects: order, id. order "start": one row per variety, sorted by the first week it is in season, so the chart reads top to bottom as the year unfolds. order "group": rows gathered by culinary family, each family sorted by the food's first in-season week, a food's varieties together. order "alpha": by food name, then variety, a food's varieties together. A row is labelled with the food, and a named variety follows in muted brackets as tools/bake.js names it, "Rhubarb (forced)", "Apples (Cox)". Every row is a link to its food's page. The month and week labels are a second, short SVG above the rows, in a block that sticks to the top of the viewport as the page scrolls; the rows' SVG starts its viewBox below the header so the two share x coordinates. JavaScript adds only the "today" marker and keeps the header level with the rows when they are scrolled sideways.
