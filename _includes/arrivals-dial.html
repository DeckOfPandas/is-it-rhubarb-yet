{% comment %} A whole-table wheel for one kind of food (veg, fruit, herbs, fish, meat). Expects: kind, id. Every food sits at the angle where its season begins, so the dial shows the shape of the year at a glance: where arrivals crowd and where the hungry gap is. Read clockwise from the hand for what comes next. Foods in season all year have no beginning and are listed in the hole. A season "begins" at the first in-season week not joined to an in-season week before it (the year end counts as adjacent), so a season that wraps December into January begins in the autumn, not on 1 January. Labels radiate from a month ring. Within a month, foods are spread evenly across the month's arc and dealt round three tiers of radius so neighbours do not collide; the longest names go outermost. Entries are "m <200 - name length>|slug" strings, so sorting as text orders by month, then longest name first. {% endcomment %} {%- assign C = 440 -%}{%- assign RING = 100 -%}{%- assign THICK = 16 -%} {%- assign month_starts = "1,5,9,14,18,23,27,31,36,40,44,49" | split: "," -%} {%- assign month_names = "Jan,Feb,Mar,Apr,May,Jun,Jul,Aug,Sep,Oct,Nov,Dec" | split: "," -%} {%- assign tiers = "122,196,270" | split: "," -%} {%- assign kind_groups = site.data.groups | where: "kind", include.kind -%} {%- assign keys = kind_groups | map: "key" -%} {%- assign starters = "" | split: "" -%} {%- assign allyear = "" | split: "" -%} {%- for food in site.data.foods -%} {%- if keys contains food.group -%} {%- assign start = 99 -%} {%- for v in food.varieties -%}{%- for r in v.weeks -%} {%- if r[2] == "in" -%} {%- assign prev = r[0] | minus: 1 -%}{%- if prev == 0 -%}{%- assign prev = 52 -%}{%- endif -%} {%- assign joined = false -%} {%- for o in v.weeks -%}{%- if o[2] == "in" and o[1] == prev -%}{%- assign joined = true -%}{%- endif -%}{%- endfor -%} {%- if joined == false and r[0] < start -%}{%- assign start = r[0] -%}{%- endif -%} {%- endif -%} {%- endfor -%}{%- endfor -%} {%- if start == 99 -%} {%- assign allyear = allyear | push: food.name -%} {%- else -%} {%- assign m = 0 -%} {%- for ms in month_starts -%}{%- assign msn = ms | plus: 0 -%}{%- if start >= msn -%}{%- assign m = forloop.index0 -%}{%- endif -%}{%- endfor -%} {%- assign lenkey = 200 | minus: food.name.size -%} {%- assign entry = m | plus: 10 | prepend: "m" | append: " " | append: lenkey | append: "|" | append: food.slug -%} {%- assign starters = starters | push: entry -%} {%- endif -%} {%- endif -%} {%- endfor -%} {%- assign starters = starters | sort -%}
